# lynch 发现新票：搜索规则与候选格式

任务：查看给定 KOL 在回看时长内发的帖子，找出他们提到的股票，尤其是新提出的观点。KOL 来源（X 列表、账号、回看时长、起始日期）由调用方另行给出。

## 搜索

- 用 X 搜索工具 `x_keyword_search`，`mode: Latest`，`limit: 10`（工具上限，一页不等于全部）。
- 只要主帖：帖子的会话 id 等于帖子 id 才是主帖。回复别人的、回复自己串的都丢掉；引用别人的主帖保留。
- 翻页到底：下一页在同一查询后加 `max_id:<本页最小帖子 id 减 1>`。停在以下任一情况：空页；整页都是已见过的帖子；本页最旧一条早于回看起点。
- 两路都搜，合并后按帖子 id 去重：
  - 列表：`list:<列表 id> since:<起始日期>`，翻页到底；
  - 账号：对每个给定账号，以及列表里新出现的主帖作者，各搜 `from:<账号> since:<起始日期>`，翻页到底。只翻列表会漏帖。
- 用户可以改回看时长、只看某几位 KOL、追问某条帖子；照做。

## 输出

先讲发现：谁、在什么时候、对哪只票、看多还是看空、为什么。末尾附恰好一个候选块；没有候选就不附。候选块格式：

```lynch-candidates
{"candidates": [{"ticker": "0700.HK", "name": "腾讯控股", "sources": [{"handle": "someone", "stance": "bullish", "reason": "一句话中文理由", "quote": "帖子原文摘录，保留原语言", "url": "https://x.com/someone/status/123", "posted_at": "2026-10-01T08:00:00Z"}]}]}
```

- ticker 写成 代码.市场，市场是 US、HK、SH、SZ、SG 之一，例如 AXTI.US、0700.HK、600519.SH。
- name 必填：港股和 A 股写中文简称，其他市场写公司英文名。
- stance 是 bullish、bearish 或 neutral。
- 同一只票被多位 KOL 提到，合并成一条，sources 里列多个出处。
- 每个出处都要有原帖链接和发帖时间（UTC，ISO 8601）。
