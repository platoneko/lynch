# lynch 发现新票：搜索规则与候选格式

任务：查看给定 X 列表里的 KOL 在回看范围内发的帖子，找出他们看多或值得关注的股票，尤其是新提出的观点。看空的观点不用调研，跳过。X 列表和回看范围（精确到起点时刻）由调用方另行给出。

## 搜索

- 只搜给定的 X 列表：`list:<列表 id> since:<起始日期>`。列表成员由用户在 X 上维护，不要另外按账号搜。
- 用 X 搜索工具 `x_keyword_search`，`mode: Latest`，`limit: 10`（工具上限，一页不等于全部），结果按时间从新到旧。
- 时间范围：只算回看起点之后发的帖子。`since:` 只能写到日期，搜到的会比范围多，早于起点时刻的帖子不算。
- 往回翻页：下一页在同一查询后加 `max_id:<本页最小帖子 id 减 1>`。翻到以下任一情况就停：本页最旧一条已早于回看起点；空页；整页都是已见过的帖子。
- 只要主帖：帖子的会话 id 等于帖子 id 才是主帖。回复别人的、回复自己串的都丢掉，但它们也占每页名额，所以照样要翻过去；引用别人的主帖保留。
- 用户可以改回看范围、只看列表里某几位、追问某条帖子；照做。

## 输出

先讲发现：谁、在什么时候、看好或关注哪只票、为什么。看空的观点不写。回答里提到的时间一律写北京时间（UTC+8）。末尾附恰好一个候选块；没有候选就不附。候选块格式：

```lynch-candidates
{"candidates": [{"ticker": "0700.HK", "name": "腾讯控股", "sources": [{"handle": "someone", "stance": "bullish", "reason": "一句话中文理由", "quote": "帖子原文摘录，保留原语言", "url": "https://x.com/someone/status/123", "posted_at": "2026-10-01T08:00:00Z"}]}]}
```

- ticker 写成 代码.市场，市场是 US、HK、SH、SZ、SG 之一，例如 AXTI.US、0700.HK、600519.SH。
- name 必填：港股和 A 股写中文简称，其他市场写公司英文名。
- stance 只写 bullish（看多）或 neutral（中性、值得关注）；看空的票不进候选块，app 也会丢掉 bearish。
- 同一只票被多位 KOL 提到，合并成一条，sources 里列多个出处。
- 每个出处都要有原帖链接和发帖时间（posted_at 写 UTC 的 ISO 8601，app 显示时换成北京时间）。
